# 시뮬레이션 오류 신고 메일 설정

사이트의 **오류 신고하기** 창에서 보내기를 누르면, 선생님 구글 계정의 Apps Script 웹 앱이 메일을 보낸다.
받는 사람은 `Code.gs`의 `RECIPIENT`(jymteacher@naver.com)로 고정되어 있다. 사이트가 보낸 값으로는 받는 사람을 바꿀 수 없다.

## 처음 한 번만 하는 배포

1. https://script.google.com 에 구글 계정으로 들어가 **새 프로젝트**를 만든다.
2. 기본으로 들어 있는 코드를 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여 넣은 뒤 저장한다. 프로젝트 이름은 `P.H.A.S.E 오류 신고`처럼 적는다.
3. 오른쪽 위 **배포 → 새 배포**를 누른다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 권한 요청이 나오면 계정을 고른 뒤 허용한다. "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**을 누른다. 메일을 보낼 권한만 요청한다.
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
6. `assets/js/report.js` 맨 위의 `REPORT_ENDPOINT = ""` 따옴표 안에 그 주소를 넣고 배포한다.

## 확인

- 웹 앱 URL을 브라우저에서 열면 `{"ok":true,"service":"phase-error-report"}`가 보인다.
- 사이트에서 신고를 한 번 보내 보고, jymteacher@naver.com 받은편지함(또는 스팸함)을 확인한다.
- 보내는 사람은 배포한 구글 계정으로 표시된다. 신고한 사람이 이메일을 적으면 그 주소가 답장 주소가 된다.

## 한도와 막는 장치

- 한 시간 20건, 하루 80건까지만 보낸다(개인 Gmail 계정의 하루 발송 한도 100통보다 적게).
- 글은 2,000자까지 받고, 5자보다 짧은 신고는 보내지 않는다.
- 사람에게 보이지 않는 빈칸을 채운 자동 전송은 메일을 보내지 않는다.

## 코드를 고친 뒤

`Code.gs`를 고쳤다면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 눌러야 반영된다. 이때 웹 앱 URL은 그대로다.
