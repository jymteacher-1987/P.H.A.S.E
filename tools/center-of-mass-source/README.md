# 질량중심 탐험 소스

React/Vite로 만드는 정적 게임입니다. 서버 없이 GitHub Pages에서 실행하며 랭킹은 `center-of-mass-885cd` Firebase 프로젝트의 익명 인증과 Firestore를 사용합니다.

## 다시 만들기

이 폴더에서 `npm install`, `npm test`, `npm run build`를 실행합니다. 저장소 루트에서 `node tools/center-of-mass-register.cjs`를 실행하면 `dist`를 게임 페이지와 assets에 복사하고 두 목록 및 캐시 버전을 갱신합니다. 이후 저장소의 `tools/README.md`에 따라 대표 사진과 Safari 검사를 실행합니다.

매단 점을 고정하고 판의 회전만 관찰하는 모형입니다. A와 B 모두 위쪽 테두리를 따라 좌우로 매다는 점을 옮겨, 손을 놓았을 때 시작 자세를 유지하는 위치를 찾습니다. 매달아 본 뒤에는 관찰 시간과 회전량에 관계없이 선을 저장할 수 있습니다. 저장할 때 그 단계의 시작 자세로 돌아가 선택한 매달점의 수직선 A 또는 B를 남깁니다. 실제 질량중심으로 자동 보정하지 않습니다. 마지막에 플레이어가 찍은 교점과 실제 중심의 거리로 점수를 계산합니다.

1.5초 동안 최대 회전이 2° 이내인 경우의 표시는 참고 안내일 뿐, 선 저장이나 정답 여부의 조건이 아닙니다. 이때 자동으로 정지한 화면은 관찰 장면을 잡아 둔 것으로 표시합니다. 미세 이동은 버튼 0.01mm, 슬라이더 0.001mm이며 버튼을 길게 누르면 반복 이동합니다. 질량중심이 매단 점 바로 위인 불안정한 평형도 회전 효과가 0이므로 중심선을 찾는 데 사용할 수 있으며, 작은 흔들림에 쉽게 기울어진다는 설명을 표시합니다. A를 남긴 뒤 판과 A선을 함께 90° 돌려 두 번째 방향을 탐색합니다. A·B는 물체 좌표에 기록되어 판과 함께 회전합니다. 판의 두께와 밀도, 중력장이 균일하다는 가정에서 질량중심과 무게중심은 같습니다.

말굽은 ∩ 방향(원래 좌표에서 180° 회전)으로 시작합니다. A선의 중심 매달점보다 질량중심이 아래에 놓여 작은 흔들림에 되돌아오는 방향이므로, 처음 자세를 유지하는 위치를 찾기 쉽습니다. 판의 좌표와 질량중심은 그대로 두고 표시 방향만 바꿔 채점과 기존 기록의 기준을 유지합니다.

휴대폰은 가로 배치를 우선 최적화하며, 세로에서도 사용할 수 있습니다. 가로에서는 판을 왼쪽에 고정하고 조작부를 오른쪽에 배치합니다. 화면 방향을 바꿔도 탐색 상태와 찍은 점은 유지합니다.

각 모양의 점수는 중심까지의 거리로 정하고 반올림한 정수로 저장합니다. 10개 답은 본인의 비공개 Firestore 문서에 5개씩 검증한 후 합계를 랭킹에 올립니다. 시간은 클라이언트 측정이므로 대회용 부정행위 방지 서버는 아닙니다. 공개 웹 설정은 비밀 키가 아니며 실제 접근 권한은 `firestore.rules`가 제한합니다. 규칙 변경은 Firebase 콘솔 또는 CLI로 별도 배포해야 합니다.
