# 질량중심 탐험 소스

React/Vite로 만드는 정적 게임입니다. 서버 없이 GitHub Pages에서 실행하며 랭킹은 `center-of-mass-885cd` Firebase 프로젝트의 익명 인증과 Firestore를 사용합니다.

## 다시 만들기

이 폴더에서 `npm install`, `npm test`, `npm run build`를 실행합니다. 저장소 루트에서 `node tools/center-of-mass-register.cjs`를 실행하면 `dist`를 게임 페이지와 assets에 복사하고 두 목록 및 캐시 버전을 갱신합니다. 이후 저장소의 `tools/README.md`에 따라 대표 사진과 Safari 검사를 실행합니다.

매단 점을 고정하고 판의 회전만 관찰하는 모형입니다. A와 B 모두 위쪽 테두리를 따라 좌우로 매다는 점을 옮깁니다. 첫 번째는 위쪽 테두리에서 선택한 지점에 매달고 흔들림이 가라앉은 뒤 실의 연장선 A를 기록합니다. 90° 돌린 다음에는 위쪽 테두리의 점을 좌우로 옮겨, 처음 1.5초 동안 회전이 2° 이내인 지점을 찾고 실제 실의 연장선 B를 기록합니다. 허용 회전각은 관찰 기준이며 완벽한 평형 판정이 아닙니다. 두 단계 모두 질량중심이 매단 점 아래에 있을 때만 선을 저장합니다. 중심이 매단 점 위에 있는 불안정한 정지 상태는 저장 조건을 통과하지 않습니다. A·B는 물체 좌표에 기록되어 물체와 함께 회전합니다. 두께와 밀도, 중력장이 균일하다는 가정에서 질량중심과 무게중심은 같습니다.

각 모양의 점수는 중심까지의 거리로 정하고 반올림한 정수로 저장합니다. 10개 답은 본인의 비공개 Firestore 문서에 5개씩 검증한 후 합계를 랭킹에 올립니다. 시간은 클라이언트 측정이므로 대회용 부정행위 방지 서버는 아닙니다. 공개 웹 설정은 비밀 키가 아니며 실제 접근 권한은 `firestore.rules`가 제한합니다. 규칙 변경은 Firebase 콘솔 또는 CLI로 별도 배포해야 합니다.
