# 질량중심 탐험 소스

React/Vite로 만드는 정적 게임입니다. 서버 없이 GitHub Pages에서 실행하며 랭킹은 `center-of-mass-885cd` Firebase 프로젝트의 익명 인증과 Firestore를 사용합니다.

## 다시 만들기

이 폴더에서 `npm install`, `npm test`, `npm run build`를 실행합니다. 저장소 루트에서 `node tools/center-of-mass-register.cjs`를 실행하면 `dist`를 게임 페이지와 assets에 복사하고 두 목록 및 캐시 버전을 갱신합니다. 이후 저장소의 `tools/README.md`에 따라 대표 사진과 Safari 검사를 실행합니다.

매단 점을 고정하고 판의 회전만 관찰하는 모형입니다. A와 B 모두 위쪽 테두리를 따라 좌우로 매다는 점을 옮겨, 손을 놓았을 때 처음 자세에서 회전하지 않는 위치를 찾습니다. 최소 1.5초 관찰하고 그 시도에서 최대 회전이 2° 이내일 때 판을 잡아 관찰한 장면을 보관하고 실제 실의 수직선 A 또는 B를 기록합니다. 성공한 관찰 이후의 정지 화면은 계속 자유롭게 매달린 상태가 아니라 잡아 둔 판입니다. 미세 이동은 버튼 0.01mm, 슬라이더 0.001mm 간격을 사용합니다. 한 번이라도 2°를 넘으면 나중에 흔들림이 가라앉아도 그 시도에서는 저장할 수 없습니다. 허용 회전각은 관찰 기준이며 완벽한 평형 판정이 아닙니다. 질량중심이 매단 점 바로 위인 불안정한 평형도 회전 효과가 0이므로 선을 기록할 수 있으며, 작은 흔들림에 쉽게 기울어진다는 설명을 표시합니다. A를 남긴 뒤 판과 A선을 함께 90° 돌려 두 번째 방향을 탐색합니다. A·B는 물체 좌표에 기록되어 물체와 함께 회전합니다. 두께와 밀도, 중력장이 균일하다는 가정에서 질량중심과 무게중심은 같습니다.

각 모양의 점수는 중심까지의 거리로 정하고 반올림한 정수로 저장합니다. 10개 답은 본인의 비공개 Firestore 문서에 5개씩 검증한 후 합계를 랭킹에 올립니다. 시간은 클라이언트 측정이므로 대회용 부정행위 방지 서버는 아닙니다. 공개 웹 설정은 비밀 키가 아니며 실제 접근 권한은 `firestore.rules`가 제한합니다. 규칙 변경은 Firebase 콘솔 또는 CLI로 별도 배포해야 합니다.
