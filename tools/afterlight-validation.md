## 해석 범위

이 기록은 명시한 이상적 광학 모형과 브라우저 검사 범위에서의 결과입니다. 실제 iPhone 하드웨어나 모든 iOS 버전의 검사를 뜻하지 않습니다. 루트 글꼴 설정 변경 검사는 실제 브라우저의 확대 기능 검사와 구분합니다. 물리 가정과 출처는 게임 내 광학 기록 및 `assets/afterlight/README.md`에 있습니다.

처음 전체 검사를 병렬 실행했을 때 기존 방탈출 검사에 자원 경쟁으로 인한 시간 초과가 있었고, 제한된 네트워크에서는 기존 운동 분석 실험의 Chart 라이브러리를 읽지 못했습니다. 게임 검사 파일을 순차 실행하도록 변경하고 정상 네트워크 조건에서 전체를 다시 실행해 위의 54개 통과 결과를 얻었습니다. 기존 실험 코드는 변경하지 않았습니다.

공개 배포 후 검사는 `node tools/afterlight-live.cjs`로 별도 수행하며, 익명 데스크톱·모바일 화면에서 마지막 카드 순서, 실제 대표 사진, 최신 게임 경로, 첫 회선 전송을 확인합니다. 방문·점수 기록에 쓰는 네트워크 요청은 차단합니다.
