# P.H.A.S.E · 가상 물리 실험실

실험·놀이를 추가하거나 수정하는 작업자는 먼저 [업로드·대표 사진·모바일 검증 안내](tools/README.md)를 읽어 주세요. Claude 등 어떤 도구로 작업해도 같은 절차를 사용합니다.

- 실험은 `experiments/`, 놀이는 `plays/`에 저장하고 두 등록 목록을 함께 갱신합니다.
- 목록의 대표 사진은 GitHub가 실제 화면을 캡처해 자동 저장합니다. 촬영 장면은 `tools/preview-scenes.json`에서 지정합니다.
- 폰·패드는 공통 뷰어에서 화면을 최대한 채우며, 컴퓨터에는 자동 전체화면을 적용하지 않습니다.
- GitHub 검사에는 Safari 계열 WebKit에서 실행하는 작은 아이폰 화면 검사도 포함됩니다. 검사 실패는 원인을 수정해야 하며, 자동화가 임의의 새 게임 코드를 알아서 고치는 것은 아닙니다.
